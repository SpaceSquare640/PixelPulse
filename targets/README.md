# targets/

Drop template images referenced by `rules.json` (`trigger.image`) here. Each
image should be a tightly-cropped screenshot of the thing you want PixelPulse
to find on screen (a button, an icon, a dialog).

---

把 `rules.json` 裡 `trigger.image` 所指向的樣板圖片放在這裡。每張圖片應該是
緊密裁切、只包含你想讓 PixelPulse 在螢幕上找到的目標（按鈕、圖示、對話框等）。
